# Verdant Reach

A small, browser-based open-world exploration game. Wander through a procedurally decorated landscape, visit Willowmere, and help Mara find five lost fireflies.

## Play

Open `index.html` in a modern web browser. No installation or build step is required.

## Controls

- **W / A / S / D** or **Arrow keys** — Move
- **Shift** — Run
- **E** — Talk to Mara or gather a nearby firefly

## Features

- Explore forests, paths, a lake, meadows, and the village.
- Find five glowing fireflies and return to Mara.
- Use the minimap to see your position and the firefly locations.
- Watch the in-game time shift from morning to evening.
